## Описание проекта

Данный проект систематически объединяет фундаментальные знания в области акушерства и гинекологии, охватывая **15 основных категорий** — ведение беременности и акушерская помощь, беременность высокого риска и осложнения, ведение родов и послеродового периода, гинекологическая онкология, репродуктивная эндокринология и бесплодие, эндометриоз и миома матки, гинекологические инфекции и воспаления, заболевания вульвы и влагалища, тазовое дно и урогинекология, помощь в подростковом и перименопаузальном периодах, генетика и пренатальный скрининг/диагностика, женское сексуальное здоровье, анатомия/физиология и фундаментальные науки, хирургические техники, а также преподавание/контроль качества — всего **187 важнейших клинических навыков**.

**Целевая аудитория**: Врачи акушеры-гинекологи, акушерки, студенты-медики, клинические ординаторы

**Учебник-источник**: «Акушерство и гинекология», 10-е издание, People's Medical Publishing House (PMPH)

## Быстрый старт

### Установка

CLI:
```bash
openclaw skills install obstetrics-gynecology-pmph-10edition
```

### Поиск навыков

```bash
# Поиск по ключевому слову
bash scripts/skill-search.sh преэклампсия

# Создание отчёта по навыкам
bash scripts/skill-report.sh
```

### Использование

Каждый навык состоит из четырёх разделов:
1. **Когда использовать** — условия для активации навыка
2. **Шаги выполнения** — стандартизированный алгоритм
3. **Предостережения** — противопоказания и предупреждения
4. **Ссылки** — дополнительные материалы
